# 旅行規劃網站

純靜態網站，不需要安裝套件。

## 啟動

```bash
cd trip-planner
python3 -m http.server 4173
```

瀏覽器開 http://localhost:4173

## 檔案

- `trip.js`：旅程資料（行程、手動確認的交通、攜帶用品）。改行程只要改這個檔，或在網站上編輯後用底部工具匯出 JSON。
- `illustrations.js`：品牌插圖與每日小圖，`pickIllustration` 依當天行程選圖。
- `app.js`、`styles.css`、`index.html`：元件與樣式。
- `vendor/`：Leaflet 地圖；`icons.js`：Font Awesome Free 圖示路徑。

草稿存在瀏覽器的 localStorage；換瀏覽器或清除資料前請先匯出 JSON。

## 假設與待查

- 目前內建的是範例行程（名古屋親子 5 日，2027/3/20–24，2 大 1 小），地點、時間、金額都是示意，不是實際查證的資料。
- 匯率預設 1 JPY = 0.21 TWD，請在「旅程設定」改成實際匯率。
- 標「估算」的交通時間是用兩點直線距離推算，地圖上的路線也是直線示意，不是真實線形；班次、車程、票價請以官方資訊為準並手動填入。
- 所有標「待確認」的營業時間與票價都還沒查證，也還沒附官方來源。
- 地圖底圖用 OpenStreetMap，只做了灰階處理；水域淡藍等自訂樣式需要另外接地圖服務的金鑰。
- 只做了本機草稿，沒有多人共編與雲端儲存。
- 字型 Huninn 從 Google Fonts 載入，離線時會退回系統字型。
